## 1. Отмена запросов

- При каждом изменении поля поиска предыдущий запрос отменяется с помощью `AbortController`.
- Идентификатор запроса предотвращает обновление интерфейса устаревшими ответами.
- `AbortSignal.timeout()` ограничивает время выполнения запроса.
- `AbortSignal.any()` объединяет ручную отмену и таймаут.
- `AbortError` игнорируется, `TimeoutError` обрабатывается как ошибка.

## 2. Задержка Debounce

- Для поиска используется задержка **500 мс**.
- Это позволяет сократить количество лишних API-запросов во время ввода.
- Отложенный вызов поиска должен отменяться при очистке поля ввода.
- если задержку сильно уменьшить - то будет сыпаться много запросов, если сильно увеличить - пользователю придется долго ждать начало поиска.

## 3. Сложность алгоритмов (Big O)

- **Маппинг:** \(O(n)\), где \(n\) — количество стран в ответе API. Каждая страна преобразуется один раз.
- **Кэширование:** не реализовано.

## 4. Принципы Clean Code

- **Single Responsibility:** запросы к API, преобразование данных, отображение интерфейса и работа с модальным окном разделены на отдельные модули.
- **Pure Functions:** `mapCountryResponse` преобразует данные API без побочных эффектов.
- **Encapsulation:** `HttpError` инкапсулирует информацию об HTTP-ошибках.
- **Reusability:** `createElement` централизует создание DOM-элементов.
- **Type Safety:** интерфейсы TypeScript описывают ответы API и данные приложения.
